# 📊 Student Marks & Grade Calculator (Python)
A simple **Python command-line program** that takes marks for multiple subjects, calculates the **total**, computes the **average**, and assigns a **grade** based on the average score.

## 🚀 Features

- Accepts marks for **6 subjects**
- Calculates **total marks**
- Computes **average marks**
- Assigns grades based on average score
- Beginner-friendly and easy to understand

---

## 🛠 Technology Used

- **Python 3**

---

## 📄 Program Logic

1. Initialize `total_marks` to 0  
2. Take marks input for 6 subjects using a loop  
3. Add each subject’s marks to `total_marks`  
4. Calculate the average marks  
5. Assign grade using conditional statements (`if-elif-else`)  
6. Display the final grade
